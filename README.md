# ggj_presentation

Closing ceremony slides for Global Game Jam Kazakhstan 2026 at Astana Hub: winners, photos, videos, sponsor and speaker logos, and a Kazakhstan map with participating cities. One `index.html` plus assets.

Status: one-off from February 2026, not maintained.
Live: https://ggj-presentation.vercel.app

Run: open `index.html` in a browser, or serve the folder with any static server.
